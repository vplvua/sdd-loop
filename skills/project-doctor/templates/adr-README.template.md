# ADR registry

Engineering decisions in MADR format. An ADR stays mutable while its
slice is in flight and becomes immutable once the slice's spec change
is archived — after that, a change is a new ADR superseding the old
one. Product decisions do NOT go here — they go to the
assumptions/open-questions journal plus a PRD edit with a changelog
bump.
